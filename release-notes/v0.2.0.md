# tributo-algorithms 0.2.0

## Highlights

- Add XGBoost multiple-metric early stopping and optional checkpoint evaluation before Bundle export.
- Preserve XGBoost model and feature-name consistency across supported export paths.
- Add X-Learner effect and policy evaluation and a full-data refit path.
- Improve Transformer empty-batch handling and classical algorithm input validation.

## Compatibility

- Python 3.12 and 3.13 and Tributo Core `>=1.2`.
- Install the relevant algorithm extra for its runtime dependencies.
- XGBoost checkpoint evaluation uses a trusted application callback and is disabled by default.

## Validation

- CI validates package contracts and algorithm tests on Python 3.12 and 3.13.
- Installed-Wheel XGBoost and X-Learner single-node Ray Jobs smoke tests run in CI.
- The single-node smoke tests do not certify multi-node execution profiles.
